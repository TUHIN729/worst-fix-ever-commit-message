# Worst Fix Ever: Funniest Commit Message

One commit-message line for a bug fix that made everything worse. A
one-character typo fix in the error-message strings flipped every failure
into a cheerful report of success — so from now on, nothing ever looks
broken again:

> `fix: typo in error message; every error now reports "success"`

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (1–100 characters, one line,
no trailing newline), guarded so an out-of-range or blank line throws
instead of writing.
